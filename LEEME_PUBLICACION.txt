RB ABOGADOS — ACTUALIZACIÓN DEL FORMULARIO

1. Reemplaza solamente index.html en el repositorio CONSULT-droid-beep/rb-abogados.
2. Conserva la carpeta img tal como está.
3. En GitHub abre index.html > lápiz Edit > pega el contenido del nuevo archivo > Commit changes.
4. Espera a que GitHub Pages publique el cambio; abre https://consult-droid-beep.github.io/rb-abogados/#formulario y actualiza con Ctrl+F5.
5. Prueba el formulario: debe abrir WhatsApp con el mensaje precargado; el visitante todavía debe presionar Enviar en WhatsApp.
IMPORTANTE: GitHub Pages no recibe correos ni almacena formularios por sí solo. Este formulario abre WhatsApp y no guarda los datos en el sitio.
